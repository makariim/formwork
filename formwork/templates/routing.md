# Routing corrections

Save it as `docs/routing.md`, the first time a route is corrected. Not before:
an empty file is one more thing to read and holds nothing.

The director reads it before routing anything, and it beats
`formwork/route.md` wherever the two disagree.

**The person's words, never the director's.** The director transcribes what was
said, word for word, the same as a read-back. Append only. The person cuts
lines; the director never edits or rewords one.

Keep it short. A file of fifty corrections means the routing table is wrong,
and that is a brief for the kit, not a longer file.

---

```markdown
# Routing corrections

routed: 2026-11-20
in my words: bugs in the search page are tasks, never rounds

routed: 2026-12-02
in my words: anything for the landing page goes to visual first
```
